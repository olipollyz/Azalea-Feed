# Changelog
All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/).

## [v0.4.0] - 2025-10-15
Closed Playtesting Begins. First wave of community playtesters join the Azalea servers. Major performance improvements and initial feedback collection.

### Added
- Discord community server launched
- BetaHub feedback integration
- Initial spawn point balancing

### Changed
- Server performance optimization
- Loot distribution system
- Terrain collision accuracy

### Fixed
- Various terrain clipping issues
- Building placement bugs
- Water shader artifacts

## [v0.3.0] - 2025-09-20
Two massive POIs added to the map - the dangerous volcanic crater zone and the abandoned military installation.

### Added
- Volcanic Crater POI with unique loot
- Military Base complex
- Underground bunker system
- New weapon spawns

### Changed
- Forest density and variation
- Road network expansion
- Lighting across the map

### Fixed
- Pathfinding issues in urban areas
- Skybox artifacts at sunset

## [v0.2.0] - 2025-08-10
Expanded coastline with fishing villages, harbors, and beachside settlements.

### Added
- 3 fishing villages
- Harbor district
- Lighthouse POI
- Beach camping spots

### Changed
- Ocean shader quality
- Coastal terrain blending
- Boat spawn locations

### Fixed
- Water penetration in buildings
- Coastal erosion visual bugs

## [v0.1.0] - 2025-07-01
Initial Alpha Release. First playable version of Azalea released on Steam Workshop. Core terrain, basic POIs, and survival mechanics implemented.

### Added
- 16km² island terrain
- 10 major POIs
- Basic loot economy
- Steam Workshop integration
